Normal ARP Request (Victim → Switch → Gateway):
Victim (192.168.1.50, MAC: AA:BB:CC:02) sends an ARP request: "Who has IP 192.168.1.1?" → Switch → Broadcast to all devices, including Gateway.
Gateway (192.168.1.1, MAC: AA:BB:CC:01) responds with ARP reply: "192.168.1.1 is at AA:BB:CC:01" → Switch → Victim.


Attacker Initiates Poisoning (Attacker → Switch → Victim):
Attacker (192.168.1.100, MAC: 11:22:33:44:55:66) sends a falsified ARP reply: "192.168.1.1 (Gateway) is at 11:22:33:44:55:66" → Switch → Victim.
Victim updates its ARP cache, associating the Gateway's IP (192.168.1.1) with the Attacker's MAC (11:22:33:44:55:66).

Attacker Poisoning Gateway (Attacker → Switch → Gateway):
Attacker sends a falsified ARP reply: "192.168.1.50 (Victim) is at 11:22:33:44:55:66" → Switch → Gateway.

Gateway updates its ARP cache, associating the Victim's IP (192.168.1.50) with the Attacker's MAC (11:22:33:44:55:66).


Victim Sends Data (Victim → Switch → Attacker):
Victim sends data intended for Gateway (to IP 192.168.1.1) → Switch → Attacker (since Victim's ARP cache now points to 11:22:33:44:55:66).

Attacker Forwards or Intercepts (Attacker → Switch → Gateway):
Attacker receives the data, can intercept or modify it, then forwards it to Gateway (to IP 192.168.1.1, MAC: AA:BB:CC:01) → Switch → Gateway.

Gateway Responds (Gateway → Switch → Attacker):

Gateway sends a reply to Victim (to IP 192.168.1.50) → Switch → Attacker (since Gateway's ARP cache points to 11:22:33:44:55:66).
Attacker Forwards Reply (Attacker → Switch → Victim):

Attacker forwards the reply to Victim → Switch → Victim, completing the man-in-the-middle communication.
